Hifz Companion — interface strings. English on the left, the current Bengali on the right.

How to use this. Read the Bengali against the English and correct anything that is wrong, awkward, or the wrong register for a ḥifẓ app. The right-hand cells are editable — type over them, then send the file back, or simply list the ones to change. Every correction goes into one file (src/strings-bn.json); no code has to be touched.

Please keep unchanged: anything inside {curly braces} — those are placeholders the app fills in with numbers, dates and names. Leave symbols, arrows and emoji (▶ ⬇ ✓ ✗ ⤢ ▤) as they are. Proper nouns, sūrah names, URLs and source names are deliberately still in English.
